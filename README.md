# Codex Template

A starter template inspired by OpenAI Codex CLI.

## Get started

```bash
pi install npm:@introspection-ai/recipes
git clone https://github.com/introspection-recipes/pi-codex
cd pi-codex
npm install
pi --recipe .
```

Web search requires `PARALLEL_API_KEY`.

See the [Recipes documentation](https://pi.recipes/docs).
